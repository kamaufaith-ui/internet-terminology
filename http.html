Term 07 — HTTP / HTTPS

Hypertext Transfer Protocol

The application-layer protocol that defines how messages are formatted and transmitted between web browsers and servers.

▶ HTTP/HTTPS — the conversation protocol of the Web.

What is HTTP?

Hypertext Transfer Protocol (HTTP) is the foundation of data communication on the World Wide Web. It is a request-response protocol where a browser (client) sends a request to a server, and the server returns a response containing the requested resource.

HTTPS is the secure version, encrypting communication using TLS (Transport Layer Security).

HTTP Methods

GET

Retrieves a resource (most web page loads).

POST

Submits data to be processed (forms, logins).

PUT / PATCH

Updates an existing resource.

DELETE

Removes a resource.

HTTP Status Codes

Common Codes

200 OK · 301 Moved Permanently · 404 Not Found · 500 Internal Server Error · 403 Forbidden · 401 Unauthorised

HTTP Versions

HTTP/1.1 (1997)

Persistent connections; still widely used.

HTTP/2 (2015)

Multiplexing, header compression, faster.

HTTP/3 (2022)

Built on QUIC/UDP for lower latency.

HTTPS

HTTP over TLS; mandatory for modern sites.
