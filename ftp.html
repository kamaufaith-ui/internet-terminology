Term 11 — FTP / SFTP

File Transfer Protocol

A standard network protocol used to transfer files between a client and a server over a TCP-based network.

▶ FTP — the workhorse protocol for moving files across networks.

What is FTP?

File Transfer Protocol (FTP) is one of the oldest Internet protocols, designed specifically for transferring files between computers on a network. It uses a client-server model and relies on TCP/IP for transport. FTP was defined in 1971 and standardised in RFC 959 in 1985.

How FTP Works

FTP uses two separate connections between client and server:

Control Connection (Port 21)

Used to send commands (login, list directory, request file) and receive status responses.

Data Connection (Port 20)

Used to actually transfer file data. Opened separately for each file transfer.

FTP Variants

Security Evolution

FTP — original; transmits credentials in plain text (insecure). FTPS — FTP with SSL/TLS encryption. SFTP — SSH File Transfer Protocol; completely different, fully encrypted (the modern standard). SCP — Secure Copy; simpler SSH-based transfer.

Modern Usage

While SFTP has largely replaced plain FTP for security reasons, FTP/SFTP remains widely used for web hosting management, uploading files to web servers, distributing software, and automated system-to-system file transfers in enterprise environments.
