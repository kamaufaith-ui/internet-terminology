Term 06 — DNS

Domain Name Server

The Internet's distributed phonebook — translating human-readable domain names into numerical IP addresses that computers understand.

▶ DNS resolution — converting names to numbers behind the scenes.

What is DNS?

The Domain Name System (DNS) is a hierarchical, distributed database that maps human-friendly domain names (like www.example.com) to machine-readable IP addresses (like 93.184.216.34). Without DNS, users would need to memorise numeric IP addresses to visit websites.

How DNS Resolution Works

When you type a URL into your browser, DNS resolution happens in milliseconds:

Resolution Steps

1. Browser checks local cache → 2. Queries OS resolver → 3. Queries Recursive Resolver (usually your ISP) → 4. Queries Root Nameserver → 5. Queries TLD Nameserver (.com, .org) → 6. Queries Authoritative Nameserver → 7. IP address returned.

DNS Record Types

A Record

Maps a domain to an IPv4 address.

AAAA Record

Maps a domain to an IPv6 address.

CNAME Record

Aliases one domain to another domain.

MX Record

Directs email to the correct mail server.

Security Concerns

DNS was originally designed without security in mind. Modern enhancements include DNSSEC (DNS Security Extensions) to prevent spoofing, and DNS over HTTPS (DoH) or DNS over TLS (DoT) to encrypt DNS queries and protect user privacy.
