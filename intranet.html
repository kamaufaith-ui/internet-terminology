Term 08 — Private Network

Intranet

A private, internal network that uses Internet technologies to share information securely within an organisation.

▶ An Intranet — the Internet's technology, turned inward for private use.

What is an Intranet?

An intranet is a private network accessible only to an organisation's staff. It uses the same technologies as the public Internet — HTTP, HTML, TCP/IP — but is restricted to authorised users within the organisation, typically protected by firewalls.

Common Uses

Intranets serve as internal hubs for companies and institutions. Typical uses include:

Typical Features

Employee portals · HR self-service · Document management · Internal news and announcements · Collaboration tools · Time and project tracking.

Intranet vs Internet vs Extranet

Internet

Public; accessible to anyone worldwide.

Intranet

Private; only accessible to internal staff.

Extranet

Extended intranet; accessible to approved external partners.

Security

Because intranets contain sensitive corporate data, they are protected by firewalls, VPNs (Virtual Private Networks) for remote access, user authentication systems, and access control lists (ACLs) to restrict which employees can view specific sections.
