Term 04 — Host Infrastructure

Web Servers

Specialised software and hardware systems that store, process, and deliver web content to clients upon request.

▶ Web servers housed in data centres — always on, always listening.

What is a Web Server?

A web server is both the hardware (a computer) and the software (a program) that stores web files and delivers them to browsers via HTTP. When you visit a website, your browser sends a request to a web server, which responds with the requested content.

Popular web server software includes Apache, Nginx, Microsoft IIS, and LiteSpeed.

How a Web Server Works

A web server listens for incoming connections on a network port (typically port 80 for HTTP and 443 for HTTPS). When a request arrives, it locates the requested resource, processes any server-side logic, and returns a response — usually an HTML page, image, or data in JSON format.

Request → Response

Browser sends GET /index.html → Server finds the file → Server responds with 200 OK + HTML content.

Static vs Dynamic Content

Static Server

Serves pre-built files (HTML, images, CSS) directly from disk without processing.

Dynamic Server

Runs application code (PHP, Python, Node.js) to generate responses on the fly, often querying databases.

Role in Architecture

Web servers are a central tier in multitier architecture, sitting between the client (browser) and backend services (databases, APIs). Modern cloud infrastructure uses load balancers to distribute traffic across many server instances for high availability and scale.
