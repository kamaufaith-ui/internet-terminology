Term 14 — Social / Interactive Web

Web 2.0

The second era of the Web — dynamic, user-generated, and defined by social interaction, collaboration, and platform-based services.

▶ Web 2.0 — the participatory, social, and interactive Web.

What is Web 2.0?

Web 2.0 describes the evolution of the Web from static, read-only pages toward dynamic, interactive, and user-generated content platforms. The term was popularised by Tim O'Reilly around 2004. It is characterised by social media, blogs, wikis, and applications where users create the content.

Defining Features

User-Generated Content

Anyone can publish: YouTube, Wikipedia, Facebook, Twitter, Reddit, blogs.

Rich Interactivity

AJAX, JavaScript frameworks (jQuery, Angular, React) enable desktop-like experiences.

Social Networks

Connections, sharing, likes, comments — the social graph.

APIs & Mashups

Services expose APIs; developers combine them to build new applications.

Web 2.0 Platforms

Landmark Web 2.0 Services

Wikipedia (2001) · Blogger (1999) · Friendster (2002) · Facebook (2004) · YouTube (2005) · Twitter (2006) · iPhone App Store (2008) · Google Maps/Gmail.

Criticisms

Web 2.0's centralization around a handful of massive platforms raised concerns about data privacy, surveillance capitalism (monetising user data), misinformation spread, and monopolistic control — issues that continue to shape debates about the Web's future and drive interest in Web 3.0.

The advertising model pioneered in Web 2.0 fundamentally changed the economy of the Internet. Platforms like Google and Facebook built billion-dollar businesses by offering free services in exchange for user data, enabling hyper-targeted advertising that proved far more effective than traditional mass-market advertising methods.
